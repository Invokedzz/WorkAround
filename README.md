# WorkAround 

Are you tired spending countless hours looking for a website or solution to extract your files?
There's no need to worry with that anymore, because WorkAround is here to solve your problems.

## Overview

This API was created to extract and read different types of files, such as .RAR/.CBR, without any complexity or burocracy. 


## Technologies

- Java 21
- Spring Boot
- Junrar
- Apache Commons
- Docker/Docker Compose

## Features

- **.RAR/.CBR extraction**: it extracts these files and storages them in `/data` folder located in the root of the project;
